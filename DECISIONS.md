# Архитектурные решения проекта

## Назначение

Файл содержит реестр важных технических и архитектурных решений. Он помогает агентам понимать, почему проект устроен определённым образом, и предотвращает повторное обсуждение уже принятых решений.

Подробности каждого решения хранятся в отдельных файлах `docs/decisions/` на основе шаблона `docs/templates/DECISION_TEMPLATE.md`.

## Правила

1. Значимые архитектурные и технические решения фиксируются письменно по шаблону `docs/templates/DECISION_TEMPLATE.md`.
2. До утверждения решение имеет статус `PROPOSED`.
3. Только согласованные решения получают статус `ACCEPTED`.
4. Если решение изменяется, старое не удаляется — ему присваивается статус `SUPERSEDED`.
5. Агент не может самостоятельно менять принятое решение без согласования с координатором проекта.
6. Каждое решение должно содержать контекст, обоснование, последствия и связанные задачи.

## Статусы

- `PROPOSED` — предложено, ожидает согласования.
- `ACCEPTED` — принято.
- `REJECTED` — отклонено.
- `SUPERSEDED` — заменено новым решением.
