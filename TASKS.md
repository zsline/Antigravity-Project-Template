## Правила

1. Каждая задача имеет уникальный ID и отдельный файл, который хранится непосредственно в `tasks/` (кроме `tasks/templates/`). Подкаталоги по статусам не создаются.
2. Статус в реестре должен совпадать со статусом в файле задачи.
3. Каждая задача связана с этапом и, если необходимо, с требованиями.
4. Задачи со статусом `ready` должны иметь критерии приёмки и определённые зависимости.
5. Завершённой считается только принятая задача.
6. Не удаляй историю выполненных задач без согласования.
7. Допустимые статусы задач: `backlog`, `ready`, `in-progress`, `review`, `blocked`, `done`. Статус `rejected` не используется (при замечаниях ревьюера задача возвращается в `in-progress`).
