# Чек-лист качества проекта

## 1. Требования
- [ ] Цели и границы проекта определены.
- [ ] Требования согласованы.
- [ ] Пользовательские сценарии описаны.
- [ ] Критерии приёмки проверяемы.
- [ ] Нет неразрешённых противоречий, блокирующих работу.

## 2. Архитектура
- [ ] Архитектура соответствует требованиям.
- [ ] Границы модулей определены.
- [ ] Контракты между компонентами согласованы.
- [ ] Зависимости обоснованы.
- [ ] Существенные решения задокументированы.

## 3. Код
- [ ] Реализация соответствует назначенной задаче.
- [ ] Нет несогласованных изменений посторонней функциональности.
- [ ] Обработка ошибок предусмотрена.
- [ ] Входные данные проверяются.
- [ ] Нет известных критических дефектов.
- [ ] Нет случайно добавленных секретов.

## 4. База данных и данные
- [ ] Структура данных соответствует требованиям.
- [ ] Ограничения целостности определены.
- [ ] Миграции проверены, если они используются.
- [ ] Чувствительные данные обрабатываются безопасно.
- [ ] Резервное копирование предусмотрено, если необходимо.

## 5. Безопасность
- [ ] Авторизация и права доступа проверены.
- [ ] Секреты хранятся вне исходного кода.
- [ ] Зависимости проверены на известные уязвимости доступными средствами.
- [ ] Опасные операции требуют надлежащих разрешений.
- [ ] Конфигурация не раскрывает чувствительные данные.

## 6. Тестирование
- [ ] Обязательные автоматические тесты пройдены.
- [ ] Основные позитивные сценарии проверены.
- [ ] Существенные негативные сценарии проверены.
- [ ] Интеграционные сценарии проверены, если применимо.
- [ ] Результаты тестирования подтверждены фактическим запуском.

## 7. Документация
- [ ] Инструкции по запуску актуальны.
- [ ] Документация соответствует фактическому поведению.
- [ ] Новые настройки описаны.
- [ ] API и интеграции документированы, если применимо.
- [ ] Известные ограничения зафиксированы.

## 8. Git и изменения
- [ ] Diff проверен.
- [ ] Нет случайных файлов и секретов.
- [ ] Чужие изменения сохранены.
- [ ] Конфликты разрешены.
- [ ] История изменений понятна.

## 9. Готовность к запуску
- [ ] Конфигурация целевого окружения проверена.
- [ ] Инструкции развёртывания подготовлены.
- [ ] План отката определён, если необходим.
- [ ] Резервное копирование и восстановление проверены, если применимо.
- [ ] Выполнена финальная приёмка.

## Правила использования

- Не каждый пункт применим к каждому проекту.
- Неприменимые пункты отмечаются `N/A` с кратким обоснованием.
- Нельзя отмечать проверку выполненной без фактического подтверждения.
- Критические и блокирующие проблемы должны быть устранены до приёмки.
- Чек-лист дополняется специфическими требованиями конкретного проекта.

- **Статус:** не проверено
- **Проверяющий:** не назначен
- **Блокирующие проблемы:** не определены
- **Решение о приёмке:** ожидает проверки
