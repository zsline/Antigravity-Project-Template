# Дизайн проекта

## Назначение

Каталог содержит визуальные референсы, макеты и материалы, определяющие внешний вид и пользовательский опыт проекта.

## Структура

- `references/screenshots/` — скриншоты интерфейсов и отдельных элементов.
- `references/websites/` — ссылки на сайты и описание интересных решений.
- `references/inspiration/` — визуальные идеи, графика, иконки и цветовые палитры.
- `mockups/` — собственные макеты и схемы интерфейса.

## Правила работы агентов

1. Перед проектированием интерфейса проверь содержимое каталога `design/`.
2. Изучи доступные референсы и определи, какие решения относятся к структуре, типографике, цветам, компонентам и поведению интерфейса.
3. Не копируй дизайн целиком автоматически. Используй референсы для определения требований и согласования собственного решения.
4. Не считай предположения о дизайне утверждёнными требованиями.
5. Если референсы противоречат друг другу, уточни приоритет у пользователя.
6. Перед основной реализацией интерфейса согласуй концепцию и ключевые решения с пользователем, если они ещё не утверждены. Если дизайн уже согласован, следуй утверждённым решениям и не запрашивай повторное согласование без существенной причины.
7. Если файлы недоступны для просмотра или содержимое не удалось распознать, сообщи об этом явно.

## Рекомендации по материалам

По возможности указывай источник каждого референса и поясняй, что именно необходимо изучить: композицию, навигацию, карточки, формы, типографику, адаптивность или другое решение.

Не помещай секреты, пароли, ключи API и персональные данные в материалы дизайна.
